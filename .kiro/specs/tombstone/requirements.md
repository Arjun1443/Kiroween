# Requirements

1. When a reader submits 1–5 public URLs, the desk shall produce an independent outcome for each distinct input.
2. When an original page returns 404 or 410, the app shall label the origin dead. Access failures shall have a separate status.
3. When the archive returns a valid capture, the card shall separate capture time from publication metadata and identify its source.
4. When replay is unavailable, the app shall return a partial card with a capture link.
5. When readable evidence is available, each highlight shall reference an excerpt from that capture.
6. When bookmark files are imported, the app shall show the extracted URLs before sending them.
7. When a card is saved, reloaded, filtered, exported, or removed, the library shall reflect the action on the current device.
8. When a lookup fails or a user activates the offline sample, the UI shall announce the resulting state and identify fixture data explicitly.
